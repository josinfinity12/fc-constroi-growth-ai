Privacy Policy - FC Construye Bot

Last updated: Oct 30, 2026

FC Construye Bot is an internal automation tool owned by FC Construye.

We use TikTok Login Kit (user.info.basic) only to authenticate the owner of @fcconstruye account. We use Content Posting API (video.publish, video.upload) only to publish original construction tutorial videos to our own account @fcconstruye.

Data collected: TikTok open_id, display_name, avatar, access_token. Stored securely in GitHub Secrets. Not shared with third parties.

Contact: fcconstruye@gmail.com - Deletion on request.
