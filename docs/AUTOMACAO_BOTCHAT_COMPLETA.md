# AUTOMAÇÃO BOTCHAT - FC CONSTROI

## FERRAMENTAS:
Manychat (IG) + Evolution API (WhatsApp) + n8n (cérebro) + Kiwify + Google Sheets

## ATENDIMENTO BOT:
1. Resposta em até 5 segundos (comentário + DM)
2. Qualificação automática Nacional vs Local
3. Envio de orçamento em PDF sem você digitar
4. Combite automático de visita
5. Recuperação de carrinho Kiwify em 1h

## MODELO PDF ORÇAMENTO AUTOMÁTICO:
Usar `python-docx` para gerar: Logo FC, Nome cliente, Metragem, Valor, Validade 7 dias, Chave PIX

## PRÓXIMO PASSO TÉCNICO:
Instalar n8n local: npm install n8n -g
Conectar Evolution API: evolution-api.com
